# Sean Avila Music

Official website for Sean Avila, country music artist.

## Structure

```
index.html        Home page
css/              Stylesheets
js/               Scripts
assets/images/    Photos, logos, artwork
assets/audio/     Music clips
```

## Local development

This is a static site with no build step. Open `index.html` in a browser,
or serve the folder with any static server, for example:

```
python -m http.server 8000
```

Then visit http://localhost:8000.
